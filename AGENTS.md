# Disaster Safety Game: agent rules

An offline Android safety game for Grade 3-6 learners in the Philippines. It is built with Unity 6000.6.8f1, URP 2D, uGUI legacy `Text` and the Input System. Use the words in `CONTEXT.md` (Level, Scenario, Choice, Safe Choice, Feedback, Hint, Star, Setting, Phase, Bantay ...) in code, tests and docs.

## Batch commands

Close the Unity Editor before any batch run, because a project open in the Editor cannot be opened in batch mode. Run from any folder:

```
"C:\Program Files\Unity\Hub\Editor\6000.6.8f1\Editor\Unity.exe" -batchmode -quit -projectPath D:/GameDEV/DisasterSafety -executeMethod DisasterSafety.EditorTools.ProjectBuilder.BuildAllBatch -logFile build.log
"C:\Program Files\Unity\Hub\Editor\6000.6.8f1\Editor\Unity.exe" -batchmode -projectPath D:/GameDEV/DisasterSafety -runTests -testPlatform EditMode -testResults editmode.xml -logFile editmode.log
"C:\Program Files\Unity\Hub\Editor\6000.6.8f1\Editor\Unity.exe" -batchmode -projectPath D:/GameDEV/DisasterSafety -runTests -testPlatform PlayMode -testResults playmode.xml -logFile playmode.log
"C:\Program Files\Unity\Hub\Editor\6000.6.8f1\Editor\Unity.exe" -batchmode -projectPath D:/GameDEV/DisasterSafety -executeMethod DisasterSafety.EditorTools.MenuScreenshots.CaptureBatch -shotsDir D:/GameDEV/DisasterSafety/Screenshots -logFile shots.log
```

`-runTests` and `CaptureBatch` exit by themselves, so leave out `-quit`. Run the build before the tests and the screenshots whenever `ProjectBuilder*.cs` or the art changed. A change is done when the build succeeds and both test runs report zero failures. Then read the screenshots for the screens you touched.

## Code rules

- Gameplay rules live in `Assets/Scripts/Core` (`DisasterSafety.Core`): plain C# with no MonoBehaviour, covered by EditMode tests.
- MonoBehaviours live in `Assets/Scripts/Game`. Put one MonoBehaviour in each file, and name the file after the class.
- Scenes are generated by `ProjectBuilder.cs` and `ProjectBuilder.Level.cs`. To change a scene, change the builder and rerun `BuildAllBatch`. The `.unity` files are build output.
- Every sentence a Learner reads lives in `Assets/Scripts/Game/UIStrings.cs` or in a Scenario file under `Assets/Resources/Scenarios`. Use only characters the pixel font has (A-Z, a-z, ñ, Ñ, 0-9, basic punctuation).

## Content rules

- Every safety sentence cites a finding ID (`EQ-xx`) from `docs/research/`. A sentence with no finding stays out of the game, and a missing finding goes back to the user as a question.
- The earthquake action is always "Duck, Cover, and Hold".
- Bantay greets, guides, cheers and encourages. The Feedback card explains. Bantay's lines stay free of judging words and of Stars.
- Art and sound are finished, committed assets under `Assets/Art` and `Assets/Audio`, made by Claude from `ArtSource/`. Use them as they are. When a picture or sound is missing, ask the user for it.

## Git
